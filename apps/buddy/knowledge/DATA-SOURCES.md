SolarAssistant's SOK documentation leads to the [Current Connected SK48V100 manual](https://www.currentconnected.com/sk48v100-owner-operators-manual/), which contains specifications, communication details, software downloads and a SolarAssistant integration section. This is a concrete source-discovery chain for enrichment: integration guide -> original product documentation -> versioned specifications and connection capabilities. Retain the originating source rather than copying an entire competitor help centre. Multiple brands sharing a transport or protocol does not establish identical ratings, pinouts or firmware behaviour. Once connected, device telemetry is a separate source that can enrich the individual installation; it does not replace catalogue knowledge for photo-only onboarding.

No free universal product-specification API covering the required older batteries, controllers, inverters and industrial equipment was established in this investigation.

The SAM CSV audit is recorded in `SAM-AUDIT-2026-09-08.json`, including source URLs, Git blob hashes, SHA-256 hashes, units, columns and nonempty-field counts. All downloaded files matched the directory API's Git blob hashes. Counting nonempty fields does not validate the correctness of their values. The files have three header/metadata rows; these were excluded from the counts. The module CSV identifies version 2026.7.3 and includes a 2026-06-23 date in the inspected first record. Its 523-row Sandia library should not be added to the CEC total as unique products without deduplication. `BatteryStateful` lists four chemistry/model JSON files, not a broad catalogue of named retail batteries.

Parquet is a possible normalized output format for these bulk CSV inputs; it does not need to be the supplier's original format. The subsequent implementation adds a pinned SAM CEC importer with normalized JSONL and SQL output; see [the implementation guide](README.md). Parquet conversion is not implemented. A PVDAQ Parquet dataset and a Hugging Face SolarPanel dataset were also found, but describe operational measurements rather than a general product-specification catalogue. A Brazilian solar-products dataset appeared in search results, but direct access returned 401 and advertised counts were inconsistent, so its contents and availability remain unverified. A Fraunhofer/TUM battery-cell dataset was identified on Zenodo, but its metadata download timed out; cell specifications would not by themselves cover complete cottage battery products.

PVsyst's [lead-acid record definition](https://www.pvsyst.com/help/component-database/batteries/batteries-dialog/basic-data-lead-acid.html) documents a data-source field (usually the manufacturer, potentially an institute or user measurements), C10 normalization and optional default internal resistance. If PVsyst data access becomes available, preserve original manufacturer ratings separately from normalized or default simulation parameters. A simulation-derived value must not become a quoted manufacturer specification in Buddy. The [current general conditions](https://www.pvsyst.com/pdf/common/general-conditions-of-use-english.pdf), fetched 2026-09-08, are dated 2026-06-01; their Meteonorm export restriction is specifically about weather data and does not by itself establish component-database rights.

Recommended acquisition path: start with downloadable identity lists and direct manufacturer catalogues, using source-specific parsers for structured tables and batch AI extraction for PDFs only where needed. Keep raw source snapshots separate from normalized claims; retain URL, document hash, revision, page and rating conditions. Validate exact models, units and conflicting fields before publication. Record source-use permissions. Do not treat an LLM's confidence score as verification. Add manufacturer/product submissions later.

Evaluate ingestion on a representative set across brands and generations: field coverage, exact-model/revision accuracy, conflicting specifications, processing cost per published model and update detection. These measurements answer the data problem; synthetic row-count benchmarks do not.

Runtime: identity -> enriched catalogue -> bounded manufacturer search on a gap -> candidate enrichment -> validation -> reusable record. Fetch known document URLs directly in background jobs instead of paying for a search to rediscover them. OpenAI's current non-preview web search tool is [$10 per 1,000 calls plus model tokens](https://developers.openai.com/api/docs/pricing); cache misses and searches per miss determine the runtime search bill. A bulk licence can be more expensive at POC volume, so compare total acquisition costs rather than assuming it is cheaper.

No subscriptions, enquiries to vendors, remote database provisioning or runtime internet access for Buddy were performed. Subsequent local implementation uses the public SAM CEC bulk files; source acquisition uses pinned direct downloads and does not call an AI model.


## Manufacturer acquisition implemented — 2026-09-08

The local importer now snapshots the Rolls product directory and 207 product pages, five Victron MPPT manuals, EPEVER inverter/controller PDFs (including committed repository manuals), and the Victron SmartShunt technical table. It publishes 200 Rolls batteries, 55 MPPTs, 44 EPEVER inverters and five battery/DC monitors. Parsing is deterministic; no ingestion model calls or search API calls are required. Seven incomplete/inconsistent Rolls pages and the unsupported G3 table family are quarantined; ambiguous variants are omitted. See `manufacturer-sources.json`, `manufacturer-feeds.json` and the generated rejection report for exact provenance and coverage.

[SmartShunt technical data](https://www.victronenergy.com/media/pg/SmartShunt/en/technical-data.html) provides current ratings and electrical limits; [operation](https://www.victronenergy.com/media/pg/SmartShunt/en/operation.html) explains the SOC estimate and synchronisation. The committed VE.Direct 3.34 protocol and current Rust decoder source are separate evidence for integration readiness. Product specifications, protocol availability and a working Origin89 driver are three distinct claims. Retail prices are not stored as electrical specifications.

Manufacturer web access is not a blanket dataset redistribution licence. This implementation stores local source snapshots and provenance; confirm packaging/reuse terms before publishing a bulk downloadable dataset.

### Public certification directories

- [UL Product iQ](https://www.ul.com/software/product-sourcing-and-certifications-database), also linked by [UL Solutions Canada](https://canada.ul.com/): public certification searching with free basic registration. It replaces the legacy UL certification directory and contains Canadian as well as US information. Do not infer jurisdiction solely from a UL-named standard.
- [CSA Product Listing](https://www.csagroup.org/product-listing/): CSA's public directory. Its [official guide](https://www.csagroup.org/documents/testing-and-certification/regulators/Certified_Products_Listing_Web_Guide.pdf) documents manufacturer, file and class searches.
- [Intertek ETL Listed Mark Directory](https://www.intertek.com/directories/etl-listed-mark/): public listings for ETL-marked products.

These directories support model/mark/certificate verification. No public bulk specification API or general scraping/republication permission was established here, and no account was created or login barrier bypassed. Future direct verification should preserve exact model, body, standard/edition, file or certificate ID, jurisdiction, scope, directory link, current listing status and verification date. A failed search is unknown, not proof that a product lacks certification. Certification does not establish Origin89 protocol support or the safety of an assembled installation.

The new `certifications` field deliberately records CEC evidence as `catalogue-reported`; it does not label it directly verified. UL 1973 is the standard, not necessarily the certifying organisation. This matters for CEC rows issued by CSA, Intertek, TUV and others.


## Extended source survey — 2026-09-08

The first assessment stopped at one battery maker, two controller makers and the SAM files. The catalogue docs name the brands a cabin actually has (Victron, EPEVER, Samlex, EG4, Xantrex, Discover, Magnum, Generac, Sol-Ark, Honda, AIMS, SRNE, Pylontech, Deye, PowMr, OutBack, Schneider, Champion, Westinghouse, Kohler, Growatt, Yamaha, Firman, Renogy), and most of them had no source at all. This pass probed 128 URLs with a desktop browser user agent and downloaded fifteen files; the status, content type, byte count, PDF-link count, HTML-table count and platform hints of every probe, and the SHA-256 of every download, are in `SOURCE-SURVEY-2026-09-08.json`. No account was created, nothing was bought, no vendor was contacted, and no AI call was made. A 403 below means the site refused an anonymous fetch, which is a fact about the fetch and not about the data.

Two findings correct the first assessment:

- The California lists **do** export to Excel. `https://solarequipment.energy.ca.gov/Home/DownloadtoExcel?filename=<List>` returns a workbook for `BatteryList`, `InvertersList` and `EnergyStorage`; the `InverterBatteryList` and `InverterSolarList` names return an empty file, because both inverter lists are sheets of the one `InvertersList` workbook.
- Australia's Clean Energy Regulator publishes the Clean Energy Council approved lists as plain CSV and XLSX on `cer.gov.au`, which the Council's own site does not.

### What this changes in the acquisition path

1. **Add the two regulator adapters first.** They are spreadsheets with stable columns, they carry an exact model string per row, and the California workbook adds kWh, kW and the UL certificate. Pin each file by the "Data has not changed since" sentence and its hash, the way `sam-sources.json` pins a commit.
2. **Then the HTML makers**: Discover, U.S. Battery, Morningstar, Champion, DuroMax. Each is the Rolls shape and reuses `catalogue-html.mjs`.
3. **Then the two REST document indexes**, EG4 and Xantrex, which turn "which PDFs exist" from a crawl into a query, and after them the PDF-only makers in order of catalogue mentions: Samlex, Magnum, Sol-Ark, OutBack, Growatt, MPP Solar, LuxPower, SRNE, Generac, Kohler, Schneider.
4. **Do not scrape around a refusal.** Trojan, Honda, Deye, Renogy manuals, MCS, SunSpec, UL, CSA and Canadian Tire need a browser or a request to the owner. A 403 answered with a spoofed client is a licence problem waiting to be found.
5. **Licence is still the open question everywhere.** No manufacturer site in this survey states redistribution terms, SolarQuotes and PV*SOL are publishers' work, and even the Australian regulator's file names the one purpose it was published for. Manufacturer web access is not a dataset licence; that sentence from the first assessment still applies to every row above.
